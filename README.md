# Artifact: ML Code Smell Study

Replication package for the paper:
**"Beyond Functional Correctness: An Empirical Comparison of ML Code Smell
Prevalence in LLM-Generated and Human-Written ML Pipelines"**

---

## Repository Structure
```
artifact/
├── code/                  # Jupyter notebooks for analysis and smell detection
├── csv_results.zip        # Smell count and density results per model per file
├── descriptions.zip       # Natural language task descriptions generated by Qwen3-30B
├── model_zips.zip         # LLM-generated ML pipelines for all six models
└── README.md
```

---

## Contents

### `code/`
Jupyter notebooks used to run the smell detection pipeline, compute metrics,
and produce the results reported in the paper. Each notebook is self-contained
and annotated with inline descriptions.

### `csv_results.zip`
CSV files containing per-file smell counts and smell density values for each
of the six LLMs under evaluation and the human-written reference corpus.
One CSV file is provided per model.

### `descriptions.zip`
Natural language descriptions generated from each ML Python file using
Qwen3-30B. These descriptions were used as prompts to elicit ML pipeline
generation from the six evaluated LLMs.

### `model_zips.zip`
LLM-generated ML pipelines produced by each of the six models:
Qwen2.5-14B, Qwen2.5-Coder-14B, Mistral-14B, Codestral-22B,
GPT-OSS-20B, and GPT-OSS-Coder-20B.

## Requirements

- Python 3.8+
- Jupyter Notebook or JupyterLab
- MLScent — install via `pip install mlscent`
- Standard data science libraries: `pandas`, `numpy`, `scipy`, `matplotlib`

---

## Reproducing the Results

1. Clone the repository
```bash
   git clone https://github.com/PromaChow/artifact.git
   cd artifact
```

2. Unzip the data files
```bash
   unzip csv_results.zip
   unzip descriptions.zip
   unzip model_zips.zip
```

3. Open the notebooks in the `code/` folder and run them in order.

## Smell Detection

ML code smells are detected using
[MLScent](https://conf.researchr.org/details/cain-2025/cain-2025-call-for-papers/10/MLScent-A-tool-for-Anti-pattern-detection-in-ML-projects)
(Shivashankar and Martini, CAIN 2025), a static analysis tool implementing
76 detectors across TensorFlow, PyTorch, Scikit-learn, Hugging Face,
Pandas, NumPy, and general ML patterns.
